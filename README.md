# MacroKitchen

A meal service business project built with Laravel Blade and PHP.

## Features
- Menu browsing for customers to explore available meals.
- Custom cart logic with extras options.
- Macro calculator for personalized meal planning.
- Responsive frontend built with HTML, CSS, JavaScript, and Laravel Blade.
- Admin dashboard for managing menus, orders, and user accounts.
- Kitchen dashboard for managing orders and operations.

## Installation
1. Clone the repository:
    
    git clone https://github.com/Mhmd-Salloukh/MacroKitchen.git

2. Install dependencies:
    
    composer install
    npm install && npm run dev

3. Copy `.env.example` to `.env` and configure your database.

4. Run migrations:
    
    php artisan migrate

5. Start the local server:
    
    php artisan serve
